Como funciona a edição de layout

Todas as alterações feitas aqui são gravadas diretamente no objeto config dentro do arquivo produtos.json.

  • Cores: Alteram instantaneamente o cabeçalho, o banner, os botões de comparação e os gráficos do index.html.
  • Colunas: Ajustam a largura dos cards para mostrar mais produtos por linha em monitores widescreen.
  • Ocultar Banner: Útil para datas como Black Friday, colocando as ofertas logo no topo da tela.
